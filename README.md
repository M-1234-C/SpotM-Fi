# SpotM-Fi

SpotM-Fi is a modern offline music player inspired by the look and feel of today's most popular music streaming services, while keeping everything stored locally on your own device. Import your music library, organize playlists, customize album artwork, edit synchronized lyrics, and enjoy your music without needing an internet connection.

Designed to work on both **Windows/macOS (Desktop)** and **Android**, SpotM-Fi automatically adapts its interface to your device while providing the same core experience everywhere.

---

# Main Features

- **Smart Music Import**
  - Browse your device storage and import entire folders into your library.
  - SpotM-Fi automatically scans all supported audio files inside the selected folder and adds them to your collection.

- **Wide Audio Format Support**
  - Supports a large variety of audio formats including:
    - MP3
    - WAV
    - OGG
    - FLAC
    - M4A
    - MP4 Audio
    - AAC
    - ALAC
    - AIFF
    - AIF
    - OPUS
    - WMA (platform dependent)
    - DSF
    - DFF
    - MPEG Audio
    - and many more depending on the installed fallback libraries.

- **Custom Playlists**
  - Create unlimited playlists.
  - Add custom titles.
  - Add playlist descriptions.
  - Assign custom cover artwork.
  - Edit playlists at any time.

- **Liked Songs**
  - Quickly save your favourite music by pressing the heart icon.
  - All liked songs are automatically collected into their own dedicated playlist.

- **Automatic Album Artwork**
  - Embedded artwork inside supported audio files is automatically detected and displayed.
  - Supports embedded artwork from MP3, FLAC, M4A, OGG and many additional formats.
  - Missing artwork automatically falls back to a clean placeholder image.

- **Custom Song Covers**
  - Override embedded artwork with your own image.
  - Every track can have completely custom artwork without modifying the original audio file.

- **Built-in Album Cover Search**
  - Search online for album artwork directly inside SpotM-Fi.
  - Download and apply artwork without leaving the application.
  - Perfect for songs that don't contain embedded album art.

- **Lyrics Editor**
  - Write lyrics manually.
  - Paste lyrics from your clipboard.
  - Import lyrics from text files.
  - Edit existing lyrics whenever you like.

- **Built-in Lyrics Search**
  - Search for song lyrics directly from inside the application.
  - Supports synchronized lyrics when available.
  - No longer requires the separate SpotM-Fi-Lyrics-Finder application.

- **Synchronized Lyrics**
  - Display perfectly timed lyrics while your music plays.
  - Automatically highlights the current line during playback.
  - Compatible with standard timestamp formatting.

- **Listening Statistics**
  - Automatically records:
    - Play count
    - Skip count
    - Listening history
    - Time listened
  - These statistics are stored locally and are being collected for future smart playlist features.

- **History Maker**
  - Discover interesting facts about music history directly inside the app.
  - Learn about famous artists, albums and important events while listening.

- **Song of the Day**
  - Every day SpotM-Fi recommends a randomly selected song from your own library.

- **Artist of the Day**
  - Highlights one artist from your music collection each day.

- **Hybrid Desktop & Mobile Interface**
  - Automatically adapts to:
    - Desktop
    - Tablets
    - Android phones

- **Responsive Layout**
  - Optimized interface for every screen size.
  - Switch between Desktop and Phone layouts manually if preferred.

- **Grid Customization**
  - Change how many songs appear in each row.

  Desktop / Tablet:
  - 5 Columns
  - 6 Columns
  - 7 Columns

  Phone:
  - 2 Columns
  - 3 Columns
  - 4 Columns

- **Auto Save**
  - Every important change is automatically saved locally.
  - Includes:
    - Playlists
    - Liked Songs
    - Album Covers
    - Lyrics
    - Listening Statistics
    - User Settings
    - Recently Played Information

- **Offline First**
  - Once your music has been imported, playback requires no internet connection.
  - Internet access is only used for optional features such as artwork and lyric searching.

# Navigation

SpotM-Fi has been designed to be simple while still giving quick access to every feature.

### Sidebar

Use the sidebar to switch between:

- **Search**
- **Your Library**
- **Liked Songs**
- **Playlists**
- **History Maker**
- **Settings**

Located at the bottom of the application.

- Pause

- Repeat
- Skip Forward 10 Seconds
- Skip Backward 10 Seconds

Click or tap anywhere on the progress bar to instantly seek to a new position within the currently playing song.

The Settings page allows you to configure the application including:

- Phone Mode

1. Open **Search**.
2. Press **+ Add Folder**.
3. Browse to the folder containing your music.
4. SpotM-Fi will automatically scan every supported audio file and import it into your library.

No music files are modified during the import process.

# Help

Playlist Covers

When creating a playlist, you can personalize it with your own artwork.

Simply click the cover placeholder while creating or editing a playlist, browse your device, and choose an image.

Supported formats include:

- `.png`
- `.jpg`
- `.jpeg`
- `.webp` (platform support may vary)

You can change a playlist cover at any time by opening the playlist and clicking its artwork again.

---

Song Covers

Every individual song can also have its own custom artwork.

Open the currently playing song from the media bar and press the **picture frame** icon.

From there you can:

- Select your own image.
- Search online for album artwork directly from inside SpotM-Fi.
- Replace an existing custom cover.
- Remove the custom cover and return to the embedded artwork.

Custom artwork never modifies your original music file—it is stored separately by SpotM-Fi.

## Album Artwork

SpotM-Fi displays artwork using the following priority:

1. Your custom artwork.
2. Embedded artwork inside the audio file.
3. Downloaded artwork from the built-in cover search.
4. The default placeholder artwork.

If no artwork exists anywhere, a clean placeholder image is shown.

Custom artwork is cached locally so it loads instantly the next time you open the application.

---

## Built-in Album Cover Search

Missing album art?

Simply press the **Search Cover** button.

SpotM-Fi searches online for matching artwork and lets you apply it directly to your song without opening another application.

Artwork is downloaded, cached locally, and automatically linked to the selected track.

This makes organizing large music libraries much faster than manually downloading artwork yourself.

---

## Lyrics

SpotM-Fi includes a complete built-in lyrics editor.

Open it by pressing the **paper icon** in the media bar while music is playing.

Inside the editor you can:

- Write lyrics manually.
- Paste copied lyrics.
- Import lyrics from a `.txt` file.
- Search for lyrics online.
- Edit existing lyrics.
- Save changes instantly.

Unlike older versions, SpotM-Fi no longer requires the separate **SpotM-Fi-Lyrics-Finder** application for most users, since lyric searching is now built directly into the player.

---

## Searching Lyrics

Press the **Search Lyrics** button inside the editor.

SpotM-Fi searches online and automatically fills the editor with matching lyrics whenever available.

If synchronized lyrics exist, they will be imported with their timestamps already included.

If only plain lyrics are available, you can still synchronize them yourself.

---

## Synchronized Lyrics

To synchronize lyrics manually, place timestamps before each line using the format:

```text
[0:05:20] First lyric
[0:09:15] Second lyric
[1:24:87] Third lyric
```

Timestamp format:

```text
[minutes:seconds:milliseconds]
```

Example:

```text
[0:00:00] SpotM-Fi
[0:05:18] Playing my favourite music
[0:10:62] Offline forever
```

Once saved, SpotM-Fi automatically highlights each lyric line as the song reaches its timestamp.

Lyrics are stored inside your local save file alongside your playlists and settings, meaning they remain available even after restarting the application.

## Local Storage

All application data is stored locally on your device.

SpotM-Fi creates folders for:

- Application settings
- Cached artwork

Large music libraries are supported.

- Album artwork
- Playlist artwork
- Song metadata

# Installation

SpotM-Fi is written in Python and requires several libraries.

Installing everything is recommended for the best compatibility across desktop and Android.

Pre-built `.exe` and `.apk` releases will be added to GitHub Releases in the future once packaging has been completed.

## 1. Core Requirements (Required)

Install these first:

```bash
pip install pygame
pip install mutagen
```

These provide:

- Audio playback
- Rendering
- Input handling
- Song metadata
- Album artwork extraction
- Audio duration detection

---

## 2. Extended Audio Support (Recommended)

Install these for maximum compatibility:

```bash
pip install moviepy
pip install pydub
pip install pillow
```

These libraries improve support for:

- MP4
- M4A
- AAC
- ALAC
- Additional embedded artwork formats
- Fallback audio decoding

Installing them is highly recommended even if your library mainly contains MP3 files.

# Tips

### Organizing Your Library

Keeping your music organized into folders before importing can make searching much easier.

Example:

```text
Music/
├── Artist/
│   ├── Album/
│   │   ├── Song.mp3
│   │   ├── Song.flac
```

---

### Better Album Artwork

For the best experience:

- Use square images.
- Recommended size: **500×500** or larger.
- JPG and PNG are recommended.

---

### Lyrics

For perfectly synchronized lyrics:

- Use accurate timestamps.
- Keep one lyric per line.
- Save after editing.
- Preview while the song is playing.

---

### Large Libraries

Libraries containing thousands of songs are supported.

The first import will take the longest because SpotM-Fi needs to:

- Scan every song
- Read metadata
- Extract artwork
- Build the local library
- Generate caches

Future launches are significantly faster.

# Troubleshooting

## Music Doesn't Import

Make sure:

- The selected folder actually contains supported audio files.
- The files are not corrupted.
- SpotM-Fi has permission to access the folder.

---

## No Album Artwork

If artwork is missing:

1. Check whether the file contains embedded artwork.
2. Use the built-in Cover Search.
3. Assign your own custom image.

---

## Lyrics Don't Sync

Verify that your timestamps follow this format:

```text
[minutes:seconds:milliseconds]
```

Example:

```text
[1:23:45]
```

---

## Android Issues

If Android features are unavailable:

- Ensure **Pyjnius** is installed.
- Grant storage permissions.
- Restart the application after changing permissions.

---

## Unsupported File

Some uncommon formats require the optional fallback libraries.

Install everything listed under **Installation** for the highest compatibility.
